サーバーに追加する

DIscheduler をサーバーに追加できるのは、そのサーバーで「サーバー管理」の権限を持っている人です。

追加の手順

  1. トップページ の［サーバーに追加する］を押します。
  2. Discord の画面が開くので、追加するサーバーを選びます。
  3. Bot に渡す権限を確かめて［認証］を押します。
  4. サーバーのチャンネルで /schedule と入力し、コマンドの候補に出てくれば追加は完了です。

追加した直後は、すべてのチャンネルで、発言できる人がコマンドを使えます。使う場所を限りたい場合は、使えるチャンネルを決める の手順で設定してください。

Bot に渡す権限

権限用途区分
チャンネルを見る投稿先のチャンネルを確認する必須
メッセージを送信募集・確定のお知らせを投稿する必須
埋め込みリンク候補日時と集計を見やすく表示する必須
イベントの作成確定した日時を Discord イベントに登録する任意
イベントの管理Bot が作ったイベントを編集・削除する任意
  • 管理者（Administrator）権限は求めません。メッセージの本文も読みません。
  • イベントの権限を外して追加しても、日程調整そのものは使えます。その場合、確定したときの Discord イベントの登録だけができません。
  • Bot が募集メッセージを投稿するチャンネルでは、Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」が許可されている必要があります。チャンネルごとに権限を絞っている場合は、Bot のロールにも許可を付けてください。

サーバーから外す

DIscheduler を使わなくなったときは、Bot をサーバーから外します。外せるのは、そのサーバーで「メンバーをキック」か「サーバー管理」の権限を持っている人です。

外す前に

Bot を外すと、Bot はチャンネルのメッセージや Discord イベントを変更できなくなります。募集メッセージを「削除されました」に変えたり、Bot が登録した Discord イベントを消したりしたい場合は、外す前に、主催者が 調整を管理・削除する の手順で調整を削除してください。

手順

  1. サーバーのメンバー一覧で、DIscheduler の Bot を右クリックします（スマートフォンでは長押しします）。
  2. 「DIscheduler をキック」を選び、確認の画面でキックします。

「サーバー設定」→「連携サービス」で DIscheduler を開き、そこから外すこともできます。

外したあと

  • /schedule（/di）のコマンドは、そのサーバーで使えなくなります。
  • そのサーバーの調整、回答、サーバーの既定値などのデータは、毎日 1 時（日本時間）の自動処理で削除されます。削除したデータは元に戻せません。
  • チャンネルに投稿済みの募集メッセージやお知らせ、Bot が登録した Discord イベントは、Bot からは消せないため残ります。不要なら、サーバーの管理者が Discord で削除してください。
  • データが削除されたあとにもう一度追加したときは、初めて追加したときと同じ状態から始まります（サーバーの既定値も初期値に戻ります）。
