Updating the poll message

When the poll message is updated

StateWhen it updates
Open or closedWhen an answer is saved. If answers are saved in quick succession, updates are batched every 20 seconds.
ConfirmedTwice a day, in a batch (04:00 and 16:00 UTC).
After the deadlineChanges to "The deadline has passed" at the next 04:00 or 16:00 UTC.

The latest answers can always be seen on the answer and results pages.

Update now

The organizer's results and edit pages show when the poll message was last updated and how many answer changes aren't shown yet. Press [Update now] to update the poll message right away (once per minute per poll).

Repost

  • If the poll message gets buried in the conversation, use [Repost to the channel] to post it again. The old message is deleted.
  • If the poll message has been deleted, [Post again] is shown.
