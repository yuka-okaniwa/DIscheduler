View results and confirm

Reading the results

  • The results page lists, for each option, the number of people per answer choice and the number who haven't answered.
  • You can sort by date or by score.
  • [Show by member] shows a table of who chose what for each option. All participants can see it.

How the best option (★) is chosen

Options are compared in this order, and ★ goes to the first one that comes out ahead:

  1. Fewer "not available" answers
  2. Higher total score (by default ○ is 4 points, △ is 2 and × is 0)
  3. More "available" answers
  4. Earlier date

Remind people who haven't answered

Press [Remind people who haven't answered] to post a message to the channel that mentions everyone who hasn't answered yet. This can be done once every 12 hours per poll. It isn't available after a date is confirmed.

Confirm the date

  1. In the results, press [Confirm] for the option you want to confirm.
  2. If you like, check "Create a Discord event" and choose the location (a voice channel or any text). The voice channel or location set as the server default is filled in; if none is set, "Discord" is used (setting the default).
  3. Press [Confirm this date]. The date is confirmed and the poll message changes to show it as confirmed.

Confirming alone doesn't post an announcement to the channel. Post it with [Announce the dates] below. If a Discord event can't be created (for example, because the bot lacks the Create Events permission), the date is still confirmed and the page shows why.

Confirm more than one date

A poll can have several confirmed dates (for example, an event held over two days). Pressing [Confirm] on another option keeps the dates already confirmed and adds the new one. A Discord event can be created for each confirmed date.

Cancel a confirmation

  • Press [Cancel confirmation] on a confirmed option to cancel it. The Discord event created for that date is deleted.
  • When no confirmed dates remain, the poll goes back to open (or closed, if the deadline has passed).
  • If you change the time of a confirmed option on the edit page, its Discord event's time changes too. To delete a confirmed option, cancel its confirmation first.
  • If anyone changes their answer after a date is confirmed, the confirmed option's row shows who changed what, under "Changed after confirmation".

Announce the dates

  • When you've finished confirming or cancelling, press [Announce the dates] under "Announcement" on the results page. It posts one message to the channel listing the dates confirmed now and any dates cancelled since the last announcement.
  • "Changes not yet announced" shows how many confirmations and cancellations there have been since the last announcement.
  • You can choose "Mention the participants' role in the announcement" (or "Mention @everyone in the announcement" if participants weren't chosen by role). Mentions are limited to 3 per poll per hour; beyond that, the message is posted without a mention.
  • Announcements for the same poll can be posted up to 10 times per hour.

Event reminders

  • As a confirmed date approaches, a reminder is posted to the channel automatically. If several dates are confirmed, one is posted for each date.
  • Under "Event reminder" on the edit page, choose "On the day of the event" or "The day before the event" and a time (hourly, 0:00 to 23:00). The default is 17:00 on the day of the event. The time is in the poll's time zone.
  • No reminder is posted if that time would be after the event starts.
    For example, with the default of 17:00 on the day, events that start before 17:00 get no reminder, so choose "The day before the event" for morning or midday events. For all-day events, a reminder is posted if the time is within that day.
  • The results page shows when the reminder will be posted under each confirmed date, for example "Reminder: Thu, Nov 19 17:00".
  • The message gives the date and time, for example "(Title) starts at November 7, 2026 1:00 PM." (shown in each viewer's time zone). For all-day events it reads "(Title) is on Sat, Nov 7 (all day)."
  • For a date confirmed after its reminder time has passed, the reminder is posted within an hour. If you press [Announce the dates] before that, the announcement includes a note such as "starts in 3 hours", which takes the place of the reminder.
  • It mentions the role if participants were chosen by role, or @everyone otherwise. Without the bot's "Mention @everyone, @here, and All Roles" permission, the mention is shown but no one is notified.
  • Only one reminder is posted per date, and none for cancelled dates.
  • Messages posted to the channel are in the poll's language (the Discord language of the person who created it).
