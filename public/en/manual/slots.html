Add date options

Add date options in this order: 1. select dates → 2. choose a time → [+ Add selected dates]. You can create options with the same time for as many days as you like at once.

1. Select dates

  • One day at a time: each tap on a date selects or deselects it. You can select several.
  • A range: tap the first and last days to select every day in between. After choosing the first day, you can move to the next month with ▶ and then choose the last day.
  • On a computer, even in "One day at a time" mode, Shift-click selects the range from the day you clicked last.
  • Days before today can't be selected. Use [Clear selection] to start over.

2. Choose a time

  • Enter the start and end times. When you set the start, the end is set to one hour later automatically (you can change it afterward).
  • The clock button opens a time picker (in browsers such as Chrome and Edge).
  • If the end is earlier than the start, the option spans midnight (e.g. 23:00–1:00).
  • For an option without a time, check "All day".
  • Recently used: up to 3 time ranges recently used in the server are shown, newest first. Press one to use its start and end times.

3. Add them as options

Press [+ Add selected dates] to create an option with the chosen time for each selected date. They appear in "3. Date options".

Selecting dates alone doesn't create options. Be sure to press [+ Add selected dates]. If you try to save or publish without pressing it, you'll be asked to confirm.

Date options list

  • Options are listed in date order. Delete one with ×.
  • You can add up to 30 options.
  • You can add options even after publishing. Deleting an option that has answers asks for confirmation (its answers are deleted too).

Time zone

  • Date options are entered in the time zone set under "Time zone" on the edit page. It starts as your browser's time zone (or Japan time if it can't be determined). Type in the field to filter the list (e.g. Tokyo, Japan, +9).
  • Participants see the times in their own browser's time zone. If it differs from the poll's time zone, both times are shown side by side.
  • Changing the time zone after entering options doesn't change the options' times (the same moments in time); only how they are shown changes.
