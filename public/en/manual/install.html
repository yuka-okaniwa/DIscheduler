Add to your server

To add DIscheduler to a server, you need the Manage Server permission in that server.

Steps

  1. Press [Add to your server] on the home page.
  2. Discord opens. Choose the server to add it to.
  3. Check the permissions for the bot and press [Authorize].
  4. Type /schedule in a channel of the server. If it appears among the command suggestions, the bot has been added.

Right after the bot is added, anyone who can send messages can use the commands in every channel. To limit where they work, follow Choose where it works.

Permissions given to the bot

PermissionUsed forType
View ChannelChecking the channel it posts toRequired
Send MessagesPosting the poll and announcementsRequired
Embed LinksShowing the options and counts clearlyRequired
Create EventsAdding the confirmed date as a Discord eventOptional
Manage EventsEditing and deleting events the bot createdOptional
  • The bot doesn't ask for the Administrator permission, and it doesn't read message content.
  • Scheduling still works if you add it without the event permissions. In that case, only creating a Discord event when confirming isn't available.
  • In the channel where the bot posts the poll message, it needs View Channel, Send Messages and Embed Links. If you restrict permissions per channel, also allow them for the bot's role.

Remove from your server

When you no longer use DIscheduler, remove the bot from the server. You need the Kick Members or Manage Server permission in that server.

Before removing it

Once removed, the bot can no longer change channel messages or Discord events. If you want the poll messages changed to "Deleted" or the Discord events created by the bot removed, have the organizers delete their polls first, as described in Manage and delete polls.

Steps

  1. In the server's member list, right-click the DIscheduler bot (long-press on a phone).
  2. Choose "Kick DIscheduler" and confirm.

You can also open DIscheduler in Server Settings → Integrations and remove it there.

After removing it

  • The /schedule (/di) commands no longer work in that server.
  • The server's polls, answers, server defaults and other data are deleted by the daily cleanup at 16:00 UTC. Deleted data can't be restored.
  • Poll messages and announcements already posted, and Discord events created by the bot, remain because the bot can no longer delete them. If you don't need them, a server admin can delete them in Discord.
  • If you add the bot again after the data has been deleted, it starts fresh, as when it was first added (server defaults go back to their initial values).
