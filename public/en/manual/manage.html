Manage and delete polls

Open the list of your polls

  1. Run /schedule in any channel of the server (an empty draft in the same channel is reused, so no extra drafts are created).
  2. Press [Manage my polls] in the reply. A link to the list page arrives in a message only you can see (usable once within 10 minutes).
  3. Press [Open my polls] to open the list page in your browser.

The list shows the polls you organize in that server, most recently updated first. Polls in other servers aren't shown (open the list from that server in the same way). Only you can see the list.

What you can do in the list

  • Filter: by All, Draft, Open, Closed or Confirmed.
  • Edit: opens the edit page, where you can change the title, date options, participants and more.
  • Results: opens the results page (published polls only), where you can confirm dates and send reminders.
  • Poll message: opens the poll message in Discord.
  • Delete: deletes the poll after confirmation.

Delete a poll

  • Delete it with [Delete] on the list page, or from "Delete poll" at the bottom of the edit page.
  • Deleting removes the date options, answers and other data right away, and they can't be restored. The poll message changes to "Deleted".
  • Discord events created for the poll are deleted too.

When data is deleted automatically

DataDeleted
Drafts with nothing entered3 days after creation
Published polls6 months after the deadline (if confirmed, 6 months after the confirmed date; with several confirmed dates, after the latest one)
Server dataWhen the bot is removed from the server (how to remove it)

Deletion is done by the daily cleanup at 16:00 UTC. The list of stored data is in the security policy.
