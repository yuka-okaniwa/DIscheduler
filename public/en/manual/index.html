DIscheduler manual

DIscheduler is a bot for scheduling inside a Discord server. You can start a poll with the members of a channel or role already added as participants, and enter date options, answer, confirm and create a Discord event, all without signing up for any outside service.

How scheduling works

  1. Create a poll (organizer): run /schedule (or /di) in a channel and open the edit page from the link sent only to you. → Create a poll
  2. Add date options and publish (organizer): pick dates on the calendar, apply a time and publish. A poll message is posted to the channel. → Add date options · Publish
  3. Answer (participants): from [Answer] on the poll message, choose ○, △ or × for each option and save. → Answer
  4. Confirm the date (organizer): check the results and confirm a date. You can also post an announcement and create a Discord event. → View results and confirm

Who's who

PersonWhat they can do
OrganizerThe person who ran /schedule. They can set the date options, answer choices and participants, and publish, confirm, send reminders and delete.
ParticipantsMembers included in the poll. They can enter and change their answers and see the other participants' answers.
Server adminsThey add the bot to the server and decide where the commands work, and the defaults for choosing participants and for the Discord event location.

How to use this manual

  • Server admins setting it up for the first time: start with Add to your server and Choose where it works.
  • If you want to start a poll, read from Create a poll onward to see the steps up to publishing.
  • If you were asked to answer, Answer is all you need.
  • If something isn't working, see Troubleshooting.

Who can see answers and what data is stored are described in the security policy.
