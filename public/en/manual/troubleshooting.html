Troubleshooting

"This link has expired" is shown

Answer links can be used once within 10 minutes. Pressing an earlier link still in Discord won't open the page. Press the button again to get a new link:

  • Answer page: [Answer] on the poll message in the channel
  • Results page: [View results] on the poll message in the channel
  • Edit page and "My polls" (organizers): run /schedule and press [Manage my polls]

Once a page is open, you can keep using it in that browser for up to 12 hours.

/schedule doesn't appear among the commands

  • The channel may not be among the channels allowed in the Integrations settings. Ask a server admin (Choose where it works).
  • You may not have the Use Application Commands permission in that channel.
  • Right after the bot is added, restarting the Discord app can make the command appear.

"You're not a participant in this poll" is shown

You aren't one of the poll's participants. Ask the organizer to add you (Add and remove participants).

Participants aren't added automatically

When participants can't be collected automatically, the poll switches to "Choose manually". Search for people by name on the edit page and add them. If there would be more than 100 participants, narrow it down with a role.

The Discord event isn't created

The bot may not have the Create Events and Manage Events permissions. Ask a server admin to add them to the bot's role. Even without them, the date itself has been confirmed.

The counts in the poll message are out of date

Updates aren't always immediate; for example, after confirmation the message is updated twice a day. Organizers can update it with [Update now] on the results page (Updating the poll message).

"You've reached the limit" is shown

These limits prevent abuse (for example, 10 polls per person per hour and 20 links per person per hour). Try again after the time shown. Deleting drafts and polls you don't need frees up room under the per-channel limit.

"Today's free tier has been used up" is shown

DIscheduler runs on Cloudflare's free tier. On busy days that go over it, the service is unavailable until 00:00 UTC. Answers already entered are not lost. Please try again later.

You found a security issue

Please don't post it publicly. Report it through the contact in "Reporting a vulnerability" in the security policy.
