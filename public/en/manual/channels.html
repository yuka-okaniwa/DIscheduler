Choose where it works

This page is for server admins. DIscheduler uses Discord's built-in features to decide where and by whom the commands can be used. The bot has no allow list of its own.

Choose the channels where the commands work

  1. In Discord, open Server Settings → Integrations → DIscheduler.
  2. Under Channels, turn off All Channels and add the channels where the commands should work.
  3. Leave Roles & Members as it is (@everyone).

This applies to both /schedule and /di. In channels that aren't allowed, the commands no longer appear among the suggestions.

Choose who can use the commands in a channel

Who can use the commands in a chosen channel follows that channel's permissions. Under Edit Channel → Permissions, set the roles that are allowed Send Messages and Use Application Commands.

Because of how Discord works, members with the Manage Server permission can use the commands regardless of this setting.

The [Answer] button on poll messages isn't affected by this setting. Whether someone can answer depends on whether they are a participant in that poll.

Set the default way to choose participants

You can set, per server, who becomes a participant when the organizer doesn't specify otherwise.

DefaultParticipants
Channel (initial value)Members who can see the channel where the command was run
RoleMembers of the chosen role
ManualStarts with only the organizer, who adds people on the edit page
  1. Someone with the Manage Server permission runs /schedule in a channel.
  2. In the reply only they can see, press [Server defaults] (this button is shown only to people with the permission).
  3. Choose the method and, for Role, the role. Your choice is saved immediately.

Organizers can change the method for each poll on the edit page. The settings screen shows who last changed the defaults and when.

Set the default Discord event location

On the same settings screen, you can also set the default location used when a confirmed date is added as a Discord event. It can be either a voice channel or a location entered as text.

  1. Open [Server defaults] as above.
  2. For a voice channel, choose it in "Use a voice channel as the event location". It's saved immediately.
  3. For text, press [Enter the event location as text], type the location (up to 100 characters) and submit.

Once set, the voice channel, or the text in "Enter a location", is filled in when an organizer confirms a date. Organizers can change the location for each poll when confirming.

Submitting a text location clears the voice channel default. Submitting an empty field goes back to the initial value, "Discord". If the default voice channel is deleted, "Enter a location" is selected on the confirm screen.

Limits on creating polls

To prevent abuse and mistakes, the number of polls is limited.

  • 10 per person per hour
  • 100 per server per day
  • 20 active polls (drafts and open polls) per channel
